# Dependensi pihak ketiga

| Komponen | Pemakaian | Lisensi / sumber |
| --- | --- | --- |
| tFPDF 1.34 | Ekspor laporan PDF UTF-8; source disertakan | LGPL 2.1; `includes/pdf/COPYING.LESSER-2.1.txt`; [tFPDF](https://www.fpdf.org/en/script/script92.php) |
| DejaVu Sans Condensed | Font reguler dan tebal serta metrik PDF | `includes/pdf/font/unifont/DejaVu_LICENSE.txt`; [DejaVu Fonts](https://dejavu-fonts.github.io/) |
| Lucide | Ikon antarmuka melalui CDN | ISC; [Lucide](https://lucide.dev/) |
| GSAP 3.13.0 | Animasi antarmuka melalui CDN | Ketentuan upstream; [GSAP](https://gsap.com/) |
| Lenis 1.3.26 | Gulir antarmuka melalui CDN | MIT; [Lenis](https://github.com/darkroomengineering/lenis) |
| Inter | Tipografi melalui Google Fonts | SIL Open Font License; [Inter](https://github.com/rsms/inter) |

Berkas tFPDF, TTF, metrik font, dan teks lisensi dipertahankan dari versi fitur terbaru. Dependensi antarmuka diunduh browser dari CDN; source paket CDN tidak disalin ke repositori. Tinjau ketentuan upstream sebelum mendistribusikan ulang komponen tambahan. Tidak ada lisensi baru yang ditetapkan untuk source aplikasi ADUIN; publikasi source tidak otomatis memberikan izin penggunaan ulang.
